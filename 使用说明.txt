## 你需要准备什么

1. 一台 Windows 10/11 电脑
2. Python 3.10+（从 python.org 下载）
3. 一只手（用来摸史莱姆）

【重要】不要从微软商店装Python！去 python.org 下载！


## 第一步：安装 Python

1. 打开 https://python.org ，点击 Download
2. 运行安装包，底部勾选 "Add Python to PATH"
3. 点击 Install Now，等一两分钟
4. 验证：打开 CMD，输入：
   python --version
   显示 Python 3.xx.x 就是装好了


## 第二步：安装依赖包

打开 CMD，输入：
   python -m pip install PyQt5 pillow numpy pyautogui

等它跑完，大概一两分钟。


## 第三步：下载史莱姆

方式一（推荐）：GitHub 下载
   https://github.com/bailidashi/slime-army
   点绿色 Code 按钮 → Download ZIP → 解压

方式二：网盘下载
   【链接待补充】


## 第四步：启动

双击 pet.py，桌面出现一只紫色果冻史莱姆！


## 操作指南

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 拎起史莱姆 |
| 双击 | Q弹变大 |
| 鼠标靠近 | 史莱姆逃跑（追多会生气） |
| 右键 | 菜单：换皮肤 / 模式 / 生崽 / 合体 / 隐藏 |
| 拖文件到身上 | 吃掉文件，丢进回收站 |


## 皮肤

内置 6 套皮肤，右键菜单切换。
想自己画？打开 pixel_editor.html，像素画板，导出代码，右键导入。


## 歪瓜：自动钓鱼

1. 开 Minecraft，站水边，拿钓鱼竿，准星对水面
2. 右键 → 歪瓜 → 开始钓鱼
3. 史莱姆自动检测鱼上钩并收杆


## 模式说明

| 模式 | 行为 |
|---|---|
| 活跃模式 | 溜达，追鼠标 |
| 安静模式 | 原地不动 |
| 贪吃模式 | 频繁走动找吃的 |


## 常见问题

| 问题 | 解决 |
|---|---|
| 双击没反应 | python --version 检查 Python |
| No module named PyQt5 | pip install PyQt5 pillow numpy pyautogui |
| pip不是内部命令 | 重装Python，勾选 Add to PATH |
| 多只史莱姆 | 右键 → 生一只（最多3次） |
| 想合体 | 两只靠近，右键 → 合体 |
| 开机自启没用 | 点掉重开一次（v3.0 已修复） |
