# 桌面史莱姆宠物

## 文件说明

| 文件 | 用途 | 怎么用 |
|------|------|--------|
| `pet.py` | 主程序 | 别直接双击，用下面启动器 |
| `start.bat` | 启动器（普通） | 双击 |
| `start_debug.bat` | 启动器（显示日志） | 双击，出问题用 |
| `start.vbs` | 启动器（无黑窗） | 双击，静默启动 |
| `pixel_editor.html` | 像素画板 | 双击用浏览器打开 |
| `pixel_editor.bat` | 画板启动器 | 双击 |
