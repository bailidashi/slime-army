# 桌面史莱姆 v2.0

> 像素点阵驱动的桌面宠物 — 会走路、变色、钓鱼、生气、生崽

## 🚀 下载运行

### 方式一：直接下载（推荐）
去 [Releases](https://github.com/bailidashi/slime-army/releases) 下载 `Slime.exe`，双击运行，无需安装任何环境。

### 方式二：源码运行
需要 Python 3.10+ 和依赖：
```bash
pip install PyQt5 pillow numpy pyautogui
python pet.py
```

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `pet.py` | 主程序源码 |
| `pixel_editor.html` | 像素画板（浏览器打开） |
| `pixel_editor.bat` | 画板一键启动 |
| `start_debug.bat` | 调试启动（查看日志） |
| `slime.ico` | 图标文件 |
| `skins/` | 自定义皮肤文件夹 |

## ✨ 功能

- 🎨 **6套皮肤** + 自定义导入/删除 + 缩略图预览
- 🍮 **果冻物理** — 起跳拉伸、落地压扁、回弹衰减
- 🦎 **变色龙** — 随背景变色，支持不同融合强度
- 🧠 **3种模式** — 活跃/安静/贪吃
- 🖱️ **鼠标互动** — 靠近逃跑、追鼠标拖拽、拖文件进回收站
- 💬 **云朵气泡** — 自言自语、生气骂人、逃跑嘴炮
- 😡 **生气模式** — 拖拽3次变红不理你
- 🐣 **多只碰撞** — 生崽最多3次，每次缩70%
- 🎣 **歪瓜菜单** — Minecraft自动钓鱼（视觉/定时）
- 🔌 **开机自启** — 托盘菜单一键开关
- 🎮 **像素风菜单** — 皮肤缩略图预览

## 🛠 自定义皮肤

1. 打开 `pixel_editor.html`（浏览器）
2. 画完点导出，复制代码
3. 右键史莱姆 → 选择皮肤 → 导入皮肤
4. 粘贴代码，起名，完成！
